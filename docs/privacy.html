Privacy Policy

YT Downloader is engineered with privacy as a core architectural constraint, not an afterthought. This policy explains exactly what data we collect, what we do not collect, and how your media files are handled.

Last updated: October 2026

TL;DR Summary

We store no cookies, no user accounts, no analytics tracking, and no browsing history. Downloaded media files are automatically deleted from our server within 24 hours. We do not sell, share, or monetize any user data. Our IP-based rate limiting data is kept only in transient memory and never written to persistent storage.

1. Data We Collect

YT Downloader is a stateless media processing utility. We intentionally collect the minimum viable data required to serve download requests:

  • YouTube URL submitted: The URL you paste into the download form is used solely to perform the requested media extraction. It is stored temporarily in the job database alongside its processing status.
  • Job processing state: The job ID, current status (queued, downloading, completed, failed), video title, format type, and file path are stored in a local SQLite database to enable progress tracking in your browser session.
  • Server request logs: Standard web server access logs (IP address, request path, HTTP status code, timestamp) may be retained for up to 7 days for security analysis and rate-limit enforcement.

2. Data We Do NOT Collect

We explicitly do not collect, store, or process any of the following:

  • Personal identity information (name, email address, phone number)
  • Browser fingerprints, canvas fingerprints, or device identifiers
  • Cross-site tracking pixels or behavioral analytics profiles
  • Payment information (we charge nothing)
  • Social media logins or OAuth tokens
  • Your YouTube account credentials or cookies
  • Any data from third-party advertising networks or data brokers

3. File Storage & Automatic Purge Policy

When a download completes, the resulting media file is temporarily stored on our server filesystem under a unique UUID filename. These files are subject to a strict automated retention policy:

  • Completed media files are automatically and permanently deleted from disk 24 hours after completion.
  • Failed or expired jobs are pruned from the database on the same schedule.
  • File names on disk are random UUIDs with no connection to your identity or the video title.
  • No backups of downloaded media are retained after purge.

4. Cookies & Browser Storage

YT Downloader does not set any persistent cookies in your browser. The job list visible in your browser is maintained in sessionStorage (cleared when you close the browser tab) or localStorage (for remembered jobs) using only locally generated UUIDs. No session data is transmitted to analytics providers.

5. Third-Party Services

When you submit a YouTube URL, our backend makes outbound HTTPS requests directly to YouTube's API endpoints and CDN servers to retrieve video metadata and stream URLs. This interaction is subject to Google's and YouTube's own privacy policies. We do not route these requests through additional third-party proxy services.

We use Google Fonts hosted on fonts.googleapis.com for typography. This means your browser will contact Google's servers when loading our pages. If you prefer to avoid this, the service functions fully without custom fonts.

6. Rate Limiting & Security Logging

Your IP address is used transiently in server-side memory to enforce a per-minute rate limit (30 requests per minute by default). This rate-limit state is stored only in process memory and is never written to persistent databases, log files, or external services. It is cleared when the server process restarts.

7. Children's Privacy

This service is not directed at or designed for users under 13 years of age. We do not knowingly collect any information from children. If you believe a child has submitted personal information through this service, please contact us immediately.

8. Changes to This Policy

We may update this privacy policy to reflect changes in the application's data handling practices. Any changes will be reflected on this page with an updated revision date. We encourage users to review this page periodically.

9. Contact

Questions or concerns about this privacy policy? Visit our Contact & Support page.
