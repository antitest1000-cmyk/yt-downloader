v1.2.0 – SEO Architecture & Dedicated Format Routes

October 2026

v1.1.0 – Multi-Track Batch Engine & ZIP Packaging

September 2026
  • Bulk Processing: Added support for queuing up to 20 URLs at once with asynchronous background worker threads.
  • ZIP Export: Built 1-click ZIP archive packaging for completed batch jobs.
  • SSRF Defense Engine: Hardened server security with strict hostname validation and private IP address shielding.
  • SQLite Thread Safety: Upgraded queue persistence to SQLite WAL mode to support high concurrent write throughput.

v1.0.0 – Initial Open-Source Release

August 2026
