⚡ How Bulk YouTube Audio Extraction Works

Manually opening twenty different tabs and clicking "Convert" on each one is tedious and prone to rate limits. Our bulk audio tool uses a managed background thread pool to orchestrate batch downloads gracefully without overloading your connection or the server.

  1. Batch Validation: When you paste up to 20 URLs, our client-side parser checks URL structure, removes duplicate links, and checks for valid YouTube identifiers before a single request is sent.
  2. Queue Ingestion: The server assigns a unique batch_id and schedules individual audio jobs across a pool of concurrent worker threads. Each URL becomes an independent job_id.
  3. Stream Selection: yt-dlp selects the best native audio stream from YouTube's adaptive streaming formats. For MP3 output, FFmpeg re-encodes the AAC source to MPEG Layer III. For M4A output, the native AAC stream is remuxed into an M4A container without re-encoding, preserving the original quality.
  4. ZIP Archiving: Once all tracks finish, you can grab individual audio tracks or download the entire batch packaged as a single ZIP archive for convenience.

📦 Concurrency and Rate Management

Processing multiple audio streams simultaneously requires careful resource management. Here’s how the batch queue protects quality and speed:

  • Concurrent Workers: Up to 3 audio jobs run in parallel at any time. Additional jobs wait in an ordered in-memory queue and start automatically when a slot opens.
  • Progress Tracking: Each job reports status (queued → running → completed → failed) and download progress via live Server-Sent Events (SSE) on the page.
  • Retry Logic: Transient YouTube CDN throttling or network hiccups trigger up to 3 automatic retries per job without affecting the rest of the batch.
  • Deduplication: If you paste the same YouTube URL twice, only one audio job is created for it. Duplicates are filtered silently before submission.

❓ Frequently Asked Questions

What is the maximum number of URLs per batch?

The default limit is 20 URLs per batch on our public instance to maintain service reliability for everyone. If you self-host the application, you can configure MAX_BATCH_SIZE in your .env file to any number you wish.

Are entire playlists supported in bulk mode?

For complete playlists, we recommend using our specialized Playlist Downloader, which automatically expands up to 50 tracks from a single playlist URL without manually copying individual links.

How long are my audio files stored?

All converted audio files are automatically and permanently deleted from server storage 24 hours after completion. Download your files promptly.

Can I choose MP3 quality (bitrate) in batch mode?

Yes. The format/quality selector applies to the entire batch. Common MP3 bitrate options include 128 kbps (smaller files), 192 kbps (balanced), and 320 kbps (highest quality). M4A always uses the native YouTube bitrate (typically 128–192 kbps).
