What Is yt-dlp? Complete Beginner's Guide to Video Downloading

📅 October 15, 2026 ⏱️ 8 min read Beginners

If you've ever searched for a reliable way to download YouTube videos from the command line, you've almost certainly come across two names: youtube-dl and yt-dlp. This guide explains what yt-dlp is, why it was created, how it works under the hood, and why it became the tool of choice for developers, media archivists, and power users worldwide.

The Origin Story: From youtube-dl to yt-dlp

youtube-dl was first released in 2006 by Ricardo Garcia Gonzalez as a simple Python script to download YouTube videos from the terminal. Over the following decade it became an essential tool for media researchers, journalists documenting human rights violations via publicly uploaded footage, podcast producers, and open-source archivists preserving historically significant content from the web.

In October 2020, the Recording Industry Association of America (RIAA) sent a DMCA takedown notice to GitHub, claiming youtube-dl facilitated copyright infringement. GitHub initially complied and removed the repository, sparking a massive backlash from the open-source community, the Electronic Frontier Foundation, and legal scholars who argued that downloading publicly accessible streams for personal use is generally protected by fair use doctrines. GitHub eventually restored the repository after its legal team reviewed the claims.

However, the episode exposed a deeper problem: youtube-dl's development had slowed significantly. YouTube continuously changes its signature cipher algorithms and stream URL formats to discourage automated downloading, and a slower update cycle meant youtube-dl was increasingly failing on modern videos. In response, a group of active contributors forked the project to create yt-dlp in 2020, with a commitment to faster patch turnaround and a substantially expanded feature set.

What Makes yt-dlp Different from youtube-dl?

yt-dlp is not a cosmetic fork. It includes hundreds of substantive improvements over youtube-dl:

  • Faster development cycle: yt-dlp patches YouTube signature changes within hours to days of YouTube deploying them, compared to weeks or months for youtube-dl at its slowest periods.
  • Format sorting: yt-dlp features a powerful -S flag for format sorting that lets you specify preference criteria like codec, video height, frame rate, and file size simultaneously. This makes it trivial to always download the "best 1080p VP9 video" without constructing complex format strings.
  • Aria2c integration: Built-in support for delegating downloads to aria2c, enabling multi-connection parallel downloads for dramatically higher throughput on fast network connections.
  • SponsorBlock integration: Native support for marking or removing sponsored segments from downloads using the SponsorBlock crowdsourced database.
  • Live chat download: Ability to download YouTube live chat replay alongside video recordings.
  • Impersonation headers: --impersonate flag to mimic real browser User-Agent and header profiles to bypass basic bot-detection mechanisms on certain platforms.
  • Broader site support: yt-dlp maintains extractors for over 1,800 websites beyond YouTube, including Vimeo, Twitter/X, TikTok, Twitch VODs, SoundCloud, Bandcamp, and many more.

How yt-dlp Works: The Technical Pipeline

When you run yt-dlp https://www.youtube.com/watch?v=EXAMPLE, the tool executes several sequential stages:

  1. URL recognition: yt-dlp matches the URL against its database of extractor modules. Each site has a dedicated extractor class that knows how to parse that platform's HTML and API responses.
  2. Metadata extraction: The YouTube extractor fetches the video's ytInitialData and ytInitialPlayerResponse JavaScript objects embedded in the page HTML. These contain the video title, description, duration, uploader info, available formats, and—critically—the encrypted stream URLs.
  3. Signature decryption: YouTube obfuscates stream URLs using a JavaScript cipher that changes periodically. yt-dlp downloads and executes this cipher using its own JavaScript interpreter to decrypt the stream URLs into directly accessible HTTPS endpoints.
  4. Format selection: Based on your format specification (-f best, -f bestvideo+bestaudio, etc.), yt-dlp selects the optimal combination of video and audio streams.
  5. Download: Streams are downloaded in chunks to a temporary file. If video and audio are in separate DASH streams (common for 1080p+), both are downloaded in parallel.
  6. Post-processing: If FFmpeg is available, separate video and audio streams are merged using FFmpeg's libavformat multiplexer. Audio conversion (e.g., MP3 extraction) is performed by FFmpeg as well.

Why FFmpeg Is Essential

YouTube serves its highest quality video (1080p, 1440p, 4K) as separate DASH (Dynamic Adaptive Streaming over HTTP) audio and video streams. A 1080p video-only stream contains no audio. A separate audio-only stream (typically Opus or M4A) must be merged using FFmpeg's -c copy stream copy mode to produce a playable MP4 file. Without FFmpeg, yt-dlp can only download the combined "progressive" streams, which max out at 720p for most YouTube content.

FFmpeg is also required for audio extraction: converting a video's M4A or Opus audio track into an MP3 file requires FFmpeg's audio codec pipeline.

yt-dlp vs. Online Downloaders

Command-line tools like yt-dlp offer significant advantages over browser-based converter websites:

  • No advertisements or deceptive download buttons
  • No artificial quality caps (many free web services limit to 720p)
  • No watermarks injected into converted files
  • Full control over format selection, metadata embedding, and subtitle extraction
  • Batch downloading of playlists, channels, and search results
  • Ability to script and automate archiving workflows
