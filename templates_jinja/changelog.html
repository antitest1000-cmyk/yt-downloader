📦 Release History

Project Changelog & Updates

Tracking active development, security improvements, and extractor updates across YT Downloader releases.

v1.2.0 – SEO Architecture & Dedicated Format Routes

October 2026
  • Duplicate Route Resolution: Implemented permanent 301 redirects for legacy URLs and established clean canonical slugs (/youtube-to-mp3, /youtube-video-downloader, /bulk-youtube-to-mp3, /bulk-youtube-video-downloader).
  • Dedicated Format Tool Pages: Added dedicated landing pages for MP4, WAV, M4A, FLAC, and 4K UHD.
  • Differentiator Hubs: Launched guides for ad-free media conversion, download safety checklists, and supported platform matrices.
  • Structured JSON-LD Data: Integrated WebApplication, BreadcrumbList, and FAQPage schemas.
  • Fair Use Policy & HTML Sitemap: Published comprehensive copyright guidance and a complete human/crawler site map.

v1.1.0 – Multi-Track Batch Engine & ZIP Packaging

September 2026
  • Bulk Processing: Added support for queuing up to 20 URLs at once with asynchronous background worker threads.
  • ZIP Export: Built 1-click ZIP archive packaging for completed batch jobs.
  • SSRF Defense Engine: Hardened server security with strict hostname validation and private IP address shielding.
  • SQLite Thread Safety: Upgraded queue persistence to SQLite WAL mode to support high concurrent write throughput.

v1.0.0 – Initial Open-Source Release

August 2026
  • Core Engine: Integrated yt-dlp stream extraction with FFmpeg DASH multiplexing.
  • Formats: Support for MP3, M4A, 720p, 1080p, and 4K downloads.
  • 24-Hour Auto-Purge: Background janitor thread to permanently delete temporary files after 24 hours.
  • Dark UI System: Bespoke Vanilla CSS with aurora mesh background and micro-animations.
